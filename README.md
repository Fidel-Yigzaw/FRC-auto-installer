FRC (game tools + wpilib) auto installer

assuming the format of installation doesn't change this should work fine

- prerequisites:
  - the Nushell shell/programming language (https://www.nushell.sh)
  - Nim compiler version 2.0.8 (https://github.com/dom96/choosenim) (if you use [mise](https://mise.jdx.dev) it should set it up for you)
    - if compiling on linux, mingw
    - if compiling on windows, probably MSVC if it doesnt come pre-installed
